IPCCH dashboard - one row per model family x arm x lead time (x seed), copied from 'IPCCH detailed runs' without rescoring. 156 rows; MLP rows per seed plus a 'mean of 3 seeds' row.

Vocabulary. family = experiment design (tag family / family_title). arm = predictor within a family: persistence: No model: predicts the phase observed most recently at or before the forecast origin in the same area. Defined only on persistence_available rows.; pooled: One model for all areas.; partitioned_gated: Regional model where the historical gate accepted it for that region, pooled model elsewhere.; regional_ungated: The regional model's own prediction wherever a regional model was fitted, whatever the gate decided. Diagnostic: scored on regional_model_fitted rows only.; global_base: The global MLP alone, without a residual model.. arm_role: baseline = not trained in this run (persistence, or a model reused for comparison); candidate = trained in this run; part of the main comparison; diagnostic = trained in this run for diagnosis only (not a deployable arm). lead_months = forecast lead (origin = target month minus lead). AlphaEarth supervised partition arms: pooled: Pooled XGB quartet on compact296 (no AlphaEarth descriptors).; pooled_plus_alphaearth: Pooled XGB quartet on compact296 plus 128 AlphaEarth 2017 admin descriptors.; shared_calibration: pooled_plus_alphaearth raw outputs with one shared ridge calibration refitted each year.; regional_calibration: pooled_plus_alphaearth with shared plus regional calibration on a supervised partition map. No map was selected at any lead, so this arm equals shared_calibration exactly.. Its evaluation datasets are family-qualified (saved truth text differs in the last digits from the other families' datasets with the same keys and phases).

Metric keys read ... period_role: primary = main evaluation period of the family; holdout = later months reported separately (2026-01..2026-04, 4 target months, point estimates); combined = primary and holdout together (GeoXGB maps to 2024 only); selected_months = selected target months only (GeoXGB window probe), not a full period (actual spans in tags period.). Cohorts: all_scored: Every scored row: one area x one target month in the period with a valid IPCCH truth value. persistence_available: Rows whose area has at least one valid IPCCH observation at or before the forecast origin (target month minus lead). Only these rows have a persistence forecast, so every comparison with persistence uses this cohort. regional_model_fitted: Rows whose region got a regional model at that refit (training data with at least 500 rows, 50 areas and 6 target months), whatever the gate later decided. regional_model_fitted_and_persistence_available: regional_model_fitted rows that also have a persistence forecast; used to compare the regional model with persistence on exactly the same rows. in_partition_map: Rows whose area is covered by the frozen partition map. regional_model_fitted_both_windows: Rows in regions that can fit a regional model under both the 36-month window and full history; the only rows where the two regional arms are both real regional fits. regional_model_fitted_full_history_only: Rows in regions with too little data for a regional model in the 36-month window but enough with full history (from 2014-01); shows what a longer window adds. Metrics: binary. = crisis (phase 3+) vs not; four_class.* = phase 1|2|3|4-5; share_phase3plus_r2 = R2 of the population share in phase 3+; n_rows = rows scored. *.binary.f1.minus_persistence / minus_pooled = crisis-F1 difference to persistence / pooled on the same rows (ci_low/ci_high where a bootstrap was saved).

Comparability. Compare values only on the same evaluation dataset (Inputs; the dataset name states lead, period span and cohort). GeoXGB maps to 2024 has a different primary period (2025 only), so its primary values are not comparable with the other families' primary values. The window probe covers selected months only. No global best-model ranking is implied.

Start here. Filter tags.lead_months = '03' AND tags.aggregation != 'single_seed' (one row per family x arm; the MLP as its mean of 3 seeds), or tags.family = 'geoxgb_reference'. Then chart primary.persistence_available.binary.f1 grouped by tag arm, or primary.persistence_available.binary.f1.minus_persistence with its ci_low / ci_high.

Models tab: external catalog descriptors only (not loadable). Details, gate-decision subsets, coverage and per-period diagnostics stay in 'IPCCH detailed runs' (tag zz_prov.original_run_id). Model bundle URI/SHA tags (zz_prov.model_bundle_uri, zz_prov.model_bundle_sha256) on the older families are historical references only: their local model weights (models.tar) were intentionally removed (research retention policy, 2026-10-14) and cannot be downloaded. AlphaEarth descriptors carry an empty bundle URI; the family run's manifests/models.tar.members.json lists its model files with SHA256.

"Validity-augmented pooled"), leads 0/6/12, seed 42: six rows and downloadable models trained on Vertex AI and published
directly in this experiment (record_kind=dashboard_row, aggregation=single_run, catalog=trained_research); they are not
projections of 'IPCCH detailed runs' and carry no zz_prov plan keys or plan fingerprint. Arms: original = share-QC-valid
original IPC/CH labels; validity_augmented = originals plus monthly copies within each uniquely linked current IPC analysis's
validity window (round-level linkage assumption). Both arms: pooled XGBoost quartet on compact296 + 128 AlphaEarth 2017
descriptors (+ realized O+1..O+6 weather oracle at leads 6/12) with annual shared ridge calibration. Metric keys
primary.all_scored.* (main window) and holdout.all_scored.* (2026-01..2026-04). Samples differ between arms; metrics are generally not directly comparable (descriptive augmentation comparison, not an isolated effect). Cards: ipcch-model get <model_id> (m-…); packages: models:/.
